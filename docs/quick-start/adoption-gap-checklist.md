# WHartTest 上手记录与二开候选清单

## 使用方式

这份文档用于记录首轮联调结果，建议每完成一个模块就更新一次。目标不是写成长报告，而是尽快把问题归类：

- 原始功能是否跑通
- 卡点更偏配置、模型、执行器还是页面稳定性
- 是否值得进入二开

## 首轮验收清单

- [ ] 能访问 `http://localhost:8913` 并正常登录
- [ ] 能进入 `项目管理`、`需求管理`、`用例管理`、`UI 自动化`、`测试套件`
- [ ] 能创建一个练手项目
- [ ] 能在项目凭证中填写练习站地址
- [ ] 能创建 UI 环境配置
- [ ] 能创建公共数据
- [ ] 能看到在线执行器
- [ ] 能执行至少 3 条 UI 用例
- [ ] 能查看执行记录、截图或 Trace
- [ ] 能上传练习需求文档
- [ ] 能完成模块拆分
- [ ] 能完成至少一次需求评审
- [ ] 在 LLM 已配置前提下，能完成至少一次用例生成
